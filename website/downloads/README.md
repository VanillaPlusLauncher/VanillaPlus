# downloads/

The builds the site gives out. Upload them in the admin panel (`/admin/`, or five clicks on
the X logo): it puts the file here, records the version and makes the "Download" buttons
(`dl.php?platform=windows`, `mac-arm64`, `mac-x64`) give the one marked latest.

A file put here by hand joins the list when its name carries the version, for example
`Amethyx-Setup-1.7.0-beta.26.exe` or `Amethyx-1.7.0-mac-arm64.zip` ("Find files in downloads"
in the panel). The builds themselves are not kept in git.
