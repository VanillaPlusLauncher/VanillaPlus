Сделай сайт-визитку для скачивания лаунчера Minecraft **Vanilla+ Launcher**.

**Как должно выглядеть.** По духу как сайт ElyPrismLauncher (elyprismlauncher.github.io) или Prism Launcher (prismlauncher.org): простой, чистый, много воздуха, крупные скриншоты, одна главная кнопка «Скачать». Не копируй их тексты, логотипы и фирменный стиль — только общий подход: лаконичная главная, блок возможностей с картинками, страница загрузки, FAQ.

## Что за программа

- Vanilla+ Launcher — бесплатный лаунчер Minecraft: Java Edition для Windows 10 (с версии 1803) и Windows 11, 64-бит. Открытый исходный код, лицензия GPL-3.0.
- Репозиторий: https://github.com/VanillaPlusLauncher/VanillaPlus
- Скачивание: последний релиз https://github.com/VanillaPlusLauncher/VanillaPlus/releases/latest, файл `VanillaPlus-Setup-<версия>.exe`. Кнопка «Скачать» ведёт туда; версию и размер, если получится, подтягивай через GitHub API (`/repos/VanillaPlusLauncher/VanillaPlus/releases/latest`), а если API недоступен — просто ссылка на latest.
- Лаунчер сам обновляется после установки.

## Возможности (для блока «Что умеет»)

1. Аккаунты Microsoft, Ely.by и офлайн; вход в Microsoft и Ely.by через их официальные сайты.
2. Сборки как в Prism Launcher: Fabric, Forge, NeoForge, Quilt; группы сборок с перетаскиванием.
3. Библиотека: модпаки, моды, ресурспаки, шейдеры и датапаки с Modrinth и CurseForge, зависимости ставятся сами.
4. Оптимизация в один клик: лаунчер смотрит на компьютер и сборку, ставит моды для FPS, подбирает память и настройки; всё отменяется одной кнопкой.
5. Скины и плащи: редактор скинов с 3D-просмотром, готовые плащи, свой скин и плащ, которые видят друзья с Vanilla+.
6. Друзья как в Essential: кто в сети и во что играет, сообщения, скриншоты, приглашения в игру; друг заходит в твой мир через туннель Vanilla+ одной кнопкой — без белого IP и настройки роутера.
7. Свой сервер из сборки в один клик.
8. Перенос сборок из других лаунчеров: Prism, ElyPrism, Modrinth App, CurseForge, TLauncher, Millida и других — лаунчер находит их сам.
9. Экспорт сборки: код для друга, Modrinth (.mrpack), CurseForge (.zip), обычный .zip.
10. Семь языков: русский, английский, испанский, португальский, немецкий, французский, китайский.
11. Оформление в стиле Minecraft: панорамы разных версий игры, звуки, тёплый «ванильный» стиль.

## Страницы и блоки

- **Главная:** логотип, заголовок «Vanilla+ Launcher», подзаголовок в одну строку (например «Удобный лаунчер Minecraft с модами, скинами и друзьями»), большая кнопка «Скачать для Windows» с версией, рядом маленькая ссылка «Исходный код на GitHub». Ниже большой скриншот лаунчера.
- **Возможности:** 6–8 карточек: иконка, заголовок, 1–2 строки текста, у части — скриншот.
- **Скриншоты:** галерея с увеличением по клику (lightbox).
- **Загрузка:** кнопка, системные требования, короткая инструкция «скачай → запусти установщик → добавь аккаунт → играй», ссылка на все релизы и список изменений (CHANGELOG в репозитории).
- **FAQ:** нужна ли лицензия (нет, можно играть офлайн или через Ely.by; для серверов с проверкой лицензии нужен Microsoft), безопасно ли (открытый код, пароли вводятся только на сайтах Microsoft и Ely.by), откуда моды (Modrinth и CurseForge), как обновить (лаунчер обновляется сам).
- **Подвал:** GitHub, лицензия GPL-3.0 и строка: «Vanilla+ Launcher — неофициальный лаунчер. Не связан с Mojang Studios или Microsoft и не одобрен ими. Minecraft — товарный знак Mojang Studios.»

## Стиль

- Тёмная тема по умолчанию: фон тёплый тёмно-коричневый (#15130f – #1e1a14), карточки чуть светлее, акцент «ваниль» — тёплый жёлто-кремовый (#f2c94c / #f2e3bd), текст светлый кремовый.
- Заголовки — пиксельный шрифт Tiny5 (Google Fonts), основной текст — Inter.
- Скругления 10–14 px, мягкие тени, плавное появление блоков при прокрутке, у кнопок небольшой подъём при наведении.
- Никаких текстур, звуков и логотипов из самой игры Minecraft — только скриншоты лаунчера и свой логотип Vanilla+.

## Картинки

Логотип (PNG с прозрачным фоном) и скриншоты лаунчера я приложу к сообщению: `logo.png`, `home.png`, `builds.png`, `library.png`, `skins.png`, `friends.png`. Используй их по относительным путям `assets/…`; где картинки не хватает, оставь понятную заглушку с подписью, какой скриншот туда нужен.

## Технически

- Статичный сайт: один `index.html` + `styles.css` + `script.js`, без сборщиков, чтобы выложить на GitHub Pages.
- Адаптивный: телефон, планшет, компьютер; на телефоне меню прячется в «бургер».
- Два языка: русский по умолчанию и английский, переключатель в шапке, выбор запоминается.
- Быстрый: картинки с `loading="lazy"`, без тяжёлых библиотек.
- Доступность: нормальный контраст, alt у картинок, кнопки с понятными подписями.

В конце дай все файлы целиком и короткую инструкцию, как выложить сайт на GitHub Pages в отдельной ветке `gh-pages` или в папке `docs` репозитория.
