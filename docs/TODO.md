- Ленты без `"epoch"` — см. «Запланировано» выше.

  PHP-сервер на php74 с тестовой копией сайта.

  в архивы не входят, на хостинге лежат с прошлых загрузок.

## Известные мелочи
- README.md и README.ru.md пишут «семь языков», а их девять (русский + 8 словарей в `src/src/renderer/i18n`).
- README.md ведёт за загрузкой на GitHub Releases, а сборки выходят на сайте; раздел «New in 1.7.0 (coming soon)» не обновлялся.
- Скрипты проверок лаунчера лежат вне репозитория (`%TEMP%\rldev\mock\tt`) и однажды уже пропали при чистке;
  копии — в резервной копии. Переносить ли их в репозиторий — не решено (скрипты сайта уже в `installer/site/`).
- После сборки для Mac PowerShell иногда не запускается (EPERM) до перезапуска сессии; обход — встроенный браузер.
- `smoke.js` не идёт на сборке для Windows 7 (в Electron 22 нет `net.fetch`): для неё — `win7-1105.js` рядом.
