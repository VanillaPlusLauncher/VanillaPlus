# Сервер Vanilla+

> Это прежняя версия сервера, на Cloudflare. Сервер Amethyx переехал на хостинг сайта (`website/cloud`, PHP), а эта папка нужна только для переноса данных: [tools/README-migrate.md](tools/README-migrate.md).

Небольшой сервер для друзей и общих скинов Vanilla+. Работает на Cloudflare Workers с базой D1, бесплатного тарифа хватает для начала.

Официальный сервер работает по адресу `https://vanillaplus.vanillaplus-server.workers.dev`, лаунчер подключается к нему сам. Инструкция ниже нужна, только если хотите поднять свой.

Что он хранит:

- ник и тип аккаунта (Microsoft, Ely.by или офлайн);
- скин и плащ Vanilla+;
- список друзей и заявок;
- статус «в сети» и, если игрок разрешил, во что он играет: сборку, версию и сервер.

Пароли и токены входа сюда не попадают. Аккаунт Microsoft или Ely.by подтверждается так же, как его проверяет любой сервер Minecraft. Лаунчер «заходит» на одноразовый адрес через Mojang или Ely.by, а сервер спрашивает у них, был ли такой вход.

## Что отвечает сервер

| Адрес | Для чего |
| --- | --- |
| `GET /csl/<ms\|ely\|offline>/<ник>.json` | скин и плащ игрока для мода CustomSkinLoader (формат CustomSkinAPI) |
| `GET /textures/<sha256>` | PNG скина или плаща |
| `POST /v1/auth/challenge`, `/v1/auth/verify` | вход аккаунтов Microsoft и Ely.by |
| `POST /v1/auth/offline` | вход офлайн-аккаунта (ник закрепляется за лаунчером) |
| `PUT/DELETE /v1/me/skin`, `/v1/me/cape` | свой скин и плащ |
| `POST /v1/me/presence` | статус «в сети» / «играет» |
| `GET /v1/friends`, `POST /v1/friends/request`, `/accept`, `/decline`, `DELETE /v1/friends/<id>` | друзья |
| `POST /v1/files/start`, `PUT /v1/files/<sha256>/<часть>`, `POST /v1/packs` | загрузка файлов кода сборки (моды не с Modrinth и CurseForge, с согласия игрока) |
| `GET /packs/<id>`, `GET /packs/<id>/<sha256>/<часть>` | скачивание этих файлов лаунчером друга, без входа (ключ — случайный id) |
| `GET/POST /v1/tunnels`, `GET/DELETE /v1/tunnels/<id>` | туннели игрока: сколько есть, новый, «ещё мой?» (продлевает его), удалить |
| `GET /v1/tunnels/<id>/ws?role=control\|accept\|join` | WebSocket туннеля: хозяин мира или сервера держит `control`, на каждое подключение друга (`join`) открывает `accept`; комната `TunnelRoom` передаёт байты игры и говорит другу `ready`, когда хозяин ответил |

Туннель живёт, пока им пользуются: подключение хозяина и вопрос «ещё мой?» сдвигают его срок, а ежедневная очистка удаляет те, что не трогали 2 дня. Бесплатно у игрока до 5 туннелей одновременно. Лаунчер держит один туннель для миров, открытых для сети, и по одному на свой сервер. Каждое сообщение WebSocket в комнате считается за 1/20 запроса, а лаунчеры шлют данные пачками, так что час игры с другом стоит порядка нескольких тысяч запросов.

Файлы кода сборки лежат в отдельной базе `amethyx-files`, чтобы не занимать место аккаунтов и друзей. Каждое скачивание продлевает срок ещё на 7 дней; если кодом неделю никто не пользуется, файлы удаляет ежедневная очистка. Ограничения: файл до 64 МБ, у игрока до 150 МБ, всего до 320 МБ.

## Как запустить свой сервер

Нужен [Node.js](https://nodejs.org) и бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/sign-up).

1. Откройте терминал в папке `server`.
2. Войдите в Cloudflare. Откроется браузер, нажмите «Allow»:
   ```
   npx wrangler login
   ```
3. Создайте базу данных:
   ```
   npx wrangler d1 create vanillaplus
   ```
   Скопируйте `database_id` из ответа в `wrangler.toml` вместо `PASTE_DATABASE_ID_HERE`.
4. Создайте таблицы. Для файлов кода сборки нужна вторая база: `npx wrangler d1 create amethyx-files`, её `database_id` впишите в блок `FILES` в `wrangler.toml`.
   ```
   npx wrangler d1 execute vanillaplus --remote --file=schema.sql
   npx wrangler d1 execute amethyx-files --remote --file=files-schema.sql
   ```
5. Опубликуйте сервер:
   ```
   npx wrangler deploy
   ```
   В конце появится адрес вида `https://vanillaplus.<ваше-имя>.workers.dev`.
6. Проверьте, что сервер отвечает: открытый в браузере адрес должен показать `{"name":"Vanilla+ server","api":1}`.
7. Подключите сервер к лаунчеру одним из двух способов:
   - для всех: впишите адрес в `BUILT_IN_SERVER` в `src/src/main/cloud/cloudClient.js` и соберите лаунчер;
   - только у себя: «Настройки» → «Друзья и скины» → «Свой сервер Vanilla+».

## Ограничения бесплатного тарифа

Бесплатно доступны примерно:

- 100 000 запросов в день;
- 100 000 записей в базу в день.

Лаунчер отправляет статус раз в 5 минут, пока открыт. Этого хватает примерно на 300 игроков, которые сидят в лаунчере весь день, или на гораздо больше обычных игроков. Если станет мало, тариф Workers Paid стоит около 5 $ в месяц.

Если `npx wrangler deploy` ругается на `[[ratelimits]]`, удалите этот блок из `wrangler.toml`. Без него сервер работает, просто без ограничения частоты запросов.

## Проверка

Тесты гоняют сервер на временной базе SQLite с подменёнными ответами Mojang и Ely.by. Нужен Node.js 22.5 или новее; запускать из корня репозитория:

```
node server/test/worker.test.mjs
```
