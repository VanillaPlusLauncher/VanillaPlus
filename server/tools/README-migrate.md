# Перенос данных с Cloudflare на сайт

Старый сервер Amethyx работает на Cloudflare. Новый живёт на сайте, по адресу `https://launcher.x-world.plus/cloud/`. Эта инструкция переносит на сайт всё, что накопилось в двух базах:

- `vanillaplus`: аккаунты, скины и плащи, друзья, сообщения, картинки;
- `amethyx-files`: файлы кодов сборок.

## Перед началом

1. Папка `cloud/` уже загружена на сайт. Проверка: адрес `https://launcher.x-world.plus/cloud/` показывает `{"name":"Amethyx server","api":1}`.
2. Есть токен сайта в файле `installer\site-token.txt`. Если вы выкладывали сборки через `publish-site.ps1`, он там уже лежит. Если нет: админка → «Токены» → создать, затем вставить в этот файл.
3. Установлен Node.js, тот же, что для сборки лаунчера.

## Шаг 1. Выгрузить базы из Cloudflare

Откройте терминал в папке `server` и выполните:

```
npx wrangler d1 export vanillaplus --remote --output=vanillaplus.sql
npx wrangler d1 export amethyx-files --remote --output=amethyx-files.sql
```

Если npx спросит, можно ли установить wrangler, ответьте `y`. Если wrangler попросит войти, выполните `npx wrangler login`. Откроется браузер: войдите в свой аккаунт Cloudflare, нажмите «Allow», затем повторите команды.

## Шаг 2. Загрузить на сайт

В той же папке `server`:

```
node tools/import-to-site.mjs --db main vanillaplus.sql
node tools/import-to-site.mjs --db files amethyx-files.sql
```

Скрипт отправляет данные частями и печатает, сколько строк ушло. В конце он покажет, сколько записей теперь на сайте в каждой таблице.

## Если что-то пошло не так

- **Связь оборвалась или скрипт остановился с ошибкой.** Просто запустите ту же команду ещё раз. Каждый запуск сначала очищает эту базу на сайте и заливает её заново.
- **Сообщение «хостинг не принял такую большую часть (413)».** Добавьте к команде `--chunk-mb 1`.
- **Сообщение «одна строка таблицы blob_parts больше части».** Одна часть файла занимает около 2 МБ. В ispmanager откройте настройки PHP сайта, поставьте `post_max_size` не меньше 8M и запустите снова.
- **Хотите сначала посмотреть, что в файле, ничего не отправляя.** Добавьте к команде `--dry-run`.

## Важно

- Делайте перенос в тот момент, когда игроки переходят на новый лаунчер. Всё, что появится на Cloudflare после выгрузки, на сайт не попадёт.
- Повторный запуск стирает в этой базе на сайте то, что уже появилось там после первого переноса.
- Игрокам ничего делать не нужно. Лаунчер сам войдёт на новый сервер, а скины, друзья и сообщения останутся.
- В файлах `vanillaplus.sql` и `amethyx-files.sql` лежат данные игроков. После переноса удалите их и никогда не кладите в git.
